# HizliNot

Komut satırından hızlı not almayı ve listelemeyi sağlayan küçük bir kişisel araç.

- Proje adı: HizliNot
- MVP hedefi: not ekle ve not listele komutlariyla notlari JSON dosyasinda saklayan CLI
- Teknoloji: Python 3.10

## Depo düzeni
- docs/ → dokümantasyon
- src/ → uygulama kodu
- tests/ → testler
- scripts/ → yardımcı betikler
- configs/ → yapılandırma dosyaları
- .agent/ → agent çalışma notları ve durumu

Not: prompts/ ve skills/ klasörleri bu projede kullanılmıyor (bkz. DECISIONS.md ADR-002).
