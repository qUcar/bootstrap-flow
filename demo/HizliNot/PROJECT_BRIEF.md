# Proje Özeti — HizliNot

- Proje adı: HizliNot
- Teknoloji: Python 3.10

Hedef: Terminalden ayrılmadan tek komutla not düşebilmek; not defteri uygulaması açma zahmetini ortadan kaldırmak.
Hedef kullanıcı: Gün boyu terminalde çalışan tek kullanıcı.
MVP tanımı: not ekle ve not listele komutlariyla notlari JSON dosyasinda saklayan CLI.

Kapsam dışı (bilinçli): not silme/düzenleme, etiketleme, arama, senkronizasyon, GUI, çoklu kullanıcı.
