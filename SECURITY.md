# Security Policy

## Supported Versions
Bootstrap Flow is currently in its Alpha phase. Security patches will be applied to the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| v0.7.x  | :white_check_mark: |
| < v0.7  | :x:                |

## Privacy & Architecture
Bootstrap Flow is a local, offline-first HTML application.
- It does **not** transmit data to any backend servers.
- It does **not** include any LLM or external APIs.
- All entered project details are stored exclusively in your browser's `localStorage`.

## Reporting a Vulnerability
If you discover a security issue (e.g., an XSS vulnerability in the generated output), please use the [GitHub Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) feature on this repository.

> **IMPORTANT**: Never post security vulnerabilities, secrets, or sensitive user data in public issues.
